# FiveM-AdministrationPanel
An open-source Administration Panel for FiveM Servers (Deprecated)

### ⚠️ Important Notice
- **Status**: This project is deprecated and no longer actively developed. It was built for older versions of FiveM and may not work with the latest updates.
- **Security**: Potential vulnerabilities exist due to outdated code. Review and update before use.
- **Open-Source**: The code is fully available for anyone to fork, improve, or maintain. We encourage community contributions to keep it alive.
- **Support**: Limited support available. Check the Discord for community help.

### 🚀 Features (As of Last Update)
Dive into a powerful, web-driven toolkit for managing your FiveM server with style and precision! Here's what's packed inside:

- **⚠️ Warning System** - Issue warnings to players with detailed reasons and logging.
- **👢 Kicking Players** - Instantly remove disruptive players from your server.
- **👍 Commending Players** - Reward good behavior with commendations that boost trust scores.
- **🚫 Temporary & Permanent Banning** - Flexible ban options with expiration dates and permanent locks.
- **⏱️ Playtime Tracking** - Monitor player activity and total playtime for insights.
- **🛡️ Trust Score System** - Dynamic scoring based on behavior, playtime, and history for smarter moderation.
- **🌐 Web-Based UI** - Sleek, responsive interface for easy management from any device.
- **🔗 API for Integrations** - Robust REST API for custom integrations and automation.
- **🎛️ Custom Server Action Buttons** - Tailor buttons for quick server commands and actions.
- **📊 Basic & Advanced Statistics** - Track warns, kicks, bans, playtime, and more with visual charts.
- **🏢 Multi-Server Support** - Manage multiple FiveM servers from one panel.
- **📅 Player Join/Leave Tracking** - Log first joined, last played, and session details.
- **👥 Staff Management** - Add/remove staff with role-based access.
- **🔐 Advanced Permissions System** - Granular permissions for commands, views, and actions.
- **💬 In-Game Commands** - Execute admin commands directly from chat (e.g., /warn, /kick, /ban).
- **📝 Logging for Actions** - Comprehensive logs for all moderation actions.
- **🔌 Plugin System** - Extensible with community-maintained plugins for extra features.
- **📈 Staff Statistics** - Per-staff metrics on actions taken.
- **🎮 Steam Authentication** - Secure login via Steam OpenID for staff.
- **🤖 Discord Integration** - Webhooks for real-time notifications on actions.
- **🔄 Cron Job Automation** - Automated tasks like player data syncing.
- **🔍 User Search & IP Tracking** - Search players and view IPs (permission-based).
- **🕒 Recent Players & Queue Management** - View recent activity and manage staff queues.

### Known Issues & Limitations
- Outdated dependencies (e.g., PHP, MySQL, Steam API integrations).
- Potential SQL injection risks in older code (mitigate by updating to prepared statements).
- Incompatibility with FiveM's latest natives and resource manifests.
- No active updates for new FiveM features.

### Requirements
* Web Server with PHP (7.0+ recommended, but test for compatibility)
* MySQL Database
* Steam API Key (https://steamcommunity.com/dev/apikey)
* Cron Job Support (for automated tasks)
